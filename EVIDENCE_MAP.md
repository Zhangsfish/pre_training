## Strength scale

- **A — Real outcome:** externally realized / measured.
- **B — Operational proof:** working artifact or reproducible model.
- **C — Decision proof:** evidence directly changed a real scope, design, or resource decision.
- **D — Analysis only:** structured reasoning without external validation.

Where a cell says **A/B** or **B/C**, the experience contains multiple evidence types; this is not a numerical score.

## Verification rule

Approximate user recollections such as:
- ~RMB 1.5m resource scale;
- ~10× component cost reduction;
- ~95% peptide purity;

remain explicitly marked as unverified until primary evidence is reconstructed.
