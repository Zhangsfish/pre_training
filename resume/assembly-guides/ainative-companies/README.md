# AI Native 公司专用简历

这是张朔面向 **AI Native 公司** 的长期专用简历入口。

当前内容快照：[`current.json`](current.json)，版本日期 **2026-10-08**。

## 什么叫 AI Native 公司

这里的 **AI Native** 不是“业务里用了 AI”的行业标签，也不等于“大模型公司”。

本简历把 AI Native 公司定义为一类在生成式 AI 时代诞生或重构的 **新公司 / 新组织形态**：

- AI / Agent 是默认生产力，而不是额外工具；
- 人更集中于问题定义、判断、审美、现实约束和结果责任；
- Agent 承担越来越多研究、分析、实现和重复执行；
- 组织角色边界更流动，小团队可以拥有更宽的责任范围；
- 长期 context、外部记忆和 harness 让人机协作跨任务、跨时间持续；
- 产品、工程和组织方式会随着模型能力一起变化；
- 对个人的评价更看重学习速度、独立判断、创造力、现实反馈与把事情推进到底的能力，而不只看传统岗位标签。

**Kimi 是当前最典型的参照。** MiniMax、DeepSeek 等公司或其中部分团队也可能具备这些特征；是否归入本类，以实际组织方式和岗位要求为准，不按公司名称机械分类。

## 这份简历的核心定位

张朔长期真正研究的对象不是 AI。

> **人生理想是持续理解世界。**

长期好奇：
- 人的偏好、判断和行动如何形成；
- 人与人如何连接、合作、冲突；
- 个体行为如何经过组织、市场、制度和技术，形成更大的社会结果；
- 在科学与物理世界里，哪些关键 know-how 仍处于黑箱，怎样让它们变得可观察、可学习、可反馈。

AI 是当前最重要的手段之一。互联网极大提高了“连接”的能力；AI 正在提高“理解”的能力，并有机会借助长期 context 与现实反馈持续进步。

## 为什么这版适合 AI Native 公司

这版不把用户包装成传统“产品经理 / 算法工程师 / 科研人员”的单一身份，而用真实经历证明以下能力：

1. **形成自己的世界模型**：从产品、商业、政治经济、社会学、历史、哲学到科学实验，持续跨领域学习并更新判断。
2. **理解人**：QQ 灵犀、KIN、Food Memory 都在探索偏好、关系、context 与更深层的连接。
3. **发现问题并做成东西**：Lecture Asset、Everwhile 都来自本人工作流中的真实摩擦，直接做成 iPhone App。
4. **理解 AI 的现实边界**：PAP/ACP3 项目同时接触 wet lab、计算/模拟和 AI 协作，知道显性知识、hands-on know-how 与黑箱分别在哪里。
5. **把物理过程自动化**：自动流动多肽合成仪把化学流程拆成泵、阀、流路、时序与控制动作。
6. **理解科研生产链**：Jiadifenin 路线开发经历覆盖路线设计、小试、放大、稳定供料与下游依赖，可用于思考 CRO/CDMO 流程和自动化空间。
7. **在组织中推动复杂事情**：跨专业协作者、供应商、小型科研团队、学生与助教的真实协作经历，证明无正式权力时的组织与推进能力。
8. **AI-native 工作方式**：长期将 GitHub 等外部环境作为 persistent context / external harness，沉淀判断、状态、失败、证据和下一步，让不同 Agent 能继续长期任务。

## 简历内容原则

- **AI 是手段，不是身份。** 最高层主题是理解人、理解组织、理解世界。
- 产品项目写“遇到什么问题 → 做了什么解决方案 → 现实进展”，不罗列开发流水线。
- AI 参与的代码、CI、签名等自动化能力不冒充本人的工程技能。
- Food Memory 按当前真实规模写成个人小实验，不拔高成已形成的公共经验网络。
- 想法可以写，但明确“已做什么 / 正在做什么 / 仍是构想”；完全没有行动的点默认不进一页简历。
- 不写无必要的防御性说明。
- 避免“不是……而是……”式对照句；用正面陈述直接说明判断。
- 针对具体公司时只调整强调顺序，不改变长期研究对象和事实。

## 针对不同 AI Native 公司

这是一份“公司类型版”，不是 Kimi 私人定制版。

- **Kimi 型**：优先突出世界观、产品 taste、跨边界实践、人 + Agent 的新工作方式。
- **MiniMax 型**：在同一事实基础上提高“技术能力如何转成产品”的权重。
- **DeepSeek 型**：提高 AI for Science、专业 know-how、评测/反馈、难问题深挖的权重。
- 其他新组织：先读真实 JD，再在本快照内重排，不从零重写身份。
