# JD-specific Applications

Create one folder per application:

applications/company-role-date/
- JD.md
- MATCH.md
- RESUME.md
- INTERVIEW_EVIDENCE.md

## Assembly logic

### 1. Parse the JD
Extract:
- business result;
- decisions owned;
- required capabilities;
- observable feedback / KPIs;
- hard constraints;
- keywords.

### 2. Match evidence
Search EVIDENCE_MAP.md and experience/.

### 3. Select
Prefer fewer stronger experiences. Do not fill the page merely because information exists.

### 4. Generate
Produce one ATS-safe page following resume/STYLE.md.

### 5. Audit
For each bullet, verify:
- source experience;
- user's ownership;
- numeric provenance;
- whether result is real vs simulated;
- no unsupported inference.

### 6. Interview handoff
For every selected bullet, keep the deeper evidence story in INTERVIEW_EVIDENCE.md.
