# Experience: KIN — family-presence consumer hardware / commercial product case

> Status: resume-ready portfolio project record.
> Source: public `Zhangsfish/kin-portfolio` repository.
> Important boundary: KIN is a portfolio / business-problem-solving project, not a launched company or realized commercial result.

## Purpose

KIN is an AI-native consumer-hardware / family-app case built to test a real business question:

**Can existing wearable signals become a new family-presence consumer experience, rather than merely safety / health monitoring?**

The project is explicitly allowed to falsify its own starting thesis. Its value is the full decision process, not proving the original idea correct.

## Current product thesis

Current Gen 1:
```text
KIN Watch + Family App
```

Core loop:
```text
Sense → State → Context → Consume → Connect / Participate
```

Important thesis shift:
- GPS / 4G / PPG / fall detection / basic state inference are not treated as the main innovation;
- mature elder-watch / OEM / API supply already covers much of the sensing layer;
- the differentiated product question moved to **context, relationship meaning, voluntary checking, and participation**.

## User-owned judgment

Repository rules explicitly separate the user's opportunity / product decisions from AI-assisted research, calculation, design and implementation.

High-value user decisions include:
- starting from the concrete problem "I called my parent, they did not answer, and I do not know what they are doing";
- distinguishing safety / anomaly value from ordinary-life / presence value;
- recognizing that "state" itself may already be commoditized;
- reframing the thesis after Chinese competitor evidence showed mature hardware / state supply;
- preferring mature platforms / OEM / APIs for validation before custom hardware NRE;
- treating self-initiated checking / happiness / participation as a possible value independent of more phone calls;
- preserving uncertainty rather than fabricating user-research or business results.

## Counterevidence / thesis updating

KIN is particularly strong evidence of willingness to change the product thesis.

The repository documents a major update:
- early work considered more custom sensing / hardware differentiation;
- competitor evidence showed Chinese elder-wearable supply already covered much of that layer;
- project narrowed toward information organization / relationship semantics / state consumption;
- mature-platform validation became preferred over immediate custom hardware.

This is decision evidence, not merely research output.
