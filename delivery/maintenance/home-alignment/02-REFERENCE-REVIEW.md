# 对上传《个人主页方案 v2》的取舍

文件是参考，不是自动批准的事实或文案。用户要求结合最终经历独立判断后实施。

## 接受

- 首页继续为媒体作品画廊，QQ → SPPS → KIN顺序不变。
- 名字、北大硕士、2027届构成很薄的身份层，不放头像墙、岗位标签和技能矩阵。
- 观点放在作品后，以已看过的作品解释人的稳定兴趣。
- 保留“做出来，给你看。”和三条现有作品说明。
- 联系层只留邮箱、GitHub、简历。

## 调整

- 不另造一个大首屏加一个大画廊首屏。身份、主句和短介绍在同一紧凑区域，作品标题只做小节标题，尽快看到QQ大图。
- “简历已经说清楚的，不重复”不能绝对化。作品详情仍需解释产品机制、本人贡献和成果；视频无法替代这些信息。
- 不把教学、PET、全合成挤成三块大型画廊；但保留三个短入口和真实详情，修好已分享的教学锚点。
- 不使用“比起漂亮的故事”作为对人的自我包装；直接写怎样让判断接受现实检验，并由SPPS/PET事实支持。
- 幸福槽位此次补成正面、具体的公开表达：安心、连接、舒适和生活中的平和满足。避免用药物、疾病、同业痛苦或成瘾对立作为自我定位。
- “放下产品以后，生活仍好了一点”作为价值取向而非宣称已有消费者结果。正和用产品带给使用者的真实改善表达，不搬运私人投资/退休目标。

## 拟采用的个人层

1. 我对人为什么做选择很好奇。为什么需要、为什么付钱、什么会留在生活里；从这些问题理解产品与生意。
2. 想做能直接带来幸福的东西。一次安心的联系、一点被看见的日常、用起来更舒服的东西；希望放下产品后，生活仍然好了一点。
3. 先想清楚，再让现实回答。从目标和约束出发做小规模验证；把想法做成可体验、可运行的东西，遇到新证据再调整。

这三点表达兴趣和工作方式，不将科研成果描述为已经商业验证，也不以主观“战略能力”取代事实。
