# 试卷预览图示清晰化

依据用户 2026-10-27 的要求，把已发布的两套试卷调整为图示可看清、题干不可读。39 张预览全部改为 840 px 页宽，PDF 原生文字删除后以灰色行纹替代，再渲染为 JPEG。结构图、谱图、实验照片及其短图例保留。两卷仍分别只含 1–21、1–18 页；原卷、答题纸和中间 PDF 均未加入站点。

页面复用现有图片预览对话框，支持点击放大、Escape 关闭和焦点返回。中英文说明与 39 张图片的 SHA256 同步更新；两份专题课件 PDF 没有改动。

验证：39 页通过五张联系表逐页检查，并检查全尺寸结构图；源文档处理后的 PDF 各页提取文字为空。`npm run check` 为 0 错误、0 警告；36 项单测通过；生产构建与输出审计通过（20 页、108 文件、45,094,462 B）。真实 Chrome 在 1366 和 375 px 下测试中英文教学页，验证 39 张 840 px 图片、横向浏览、点击放大、Escape、焦点返回、两份 PDF 下载哈希及页面无横向溢出，全部通过。截图另存本机上游任务 `browser-review/`。

初次并行 check/build 引发 Vite 缓存重命名冲突，顺序重建成功。受限环境预览端口不可达，改用仅绑定 127.0.0.1 的独立临时静态服务完成浏览器验收。没有安装依赖。
