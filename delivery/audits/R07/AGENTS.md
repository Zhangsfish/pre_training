# R07 audit workspace

This folder records implementation, build, browser, publication-safety, deployment, and production verification evidence for the user-authorized R07 media gallery release.

- `REPORT.md` is the single human-readable handoff and review entry.
- `evidence.json` is the machine-readable evidence index and release record.
- `attempt-02/` contains logs and screenshots generated from the clean R07 worktree. It supersedes the attachment's earlier blocked-environment attempt.
- `verify-production.mjs` is the reproducible anonymous-browser production check.

Source-of-truth facts remain in `PROFILE.md`, `experience/`, and reviewed `publication/` data. This audit folder must not contain credentials, original private media, or unselected résumé variants. The reviewer, not the implementer, assigns final ACCEPT.
