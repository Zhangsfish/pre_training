# 写作校准记录

状态：v1.1。来自 KIN 项目申请描述与 BRM 简历版的两轮用户修改及最终确认。这里记录用户修改揭示的稳定偏好，不把 KIN 的具体事实自动迁移到其他经历。已确认长版见 [approved-kin-long-form.md](approved-kin-long-form.md)。

## 用户修改揭示的差异

| 原稿倾向 | 用户修改方向 | 可复用规则 |
|---|---|---|
| 把未接电话写成“联系失败、不了解情况” | 补出“面对未知的恐惧感” | 不停在信息缺口，继续追问它让具体的人感受到什么。 |
| 直接说“增加幸福感” | 改成“增加家人之间的连接，从而创造幸福” | 使命必须有中间机制，避免抽象价值悬空。 |
| 把用户打开概括为“处理告警或随手查看” | 强调“不是被迫处理告警，而是因为关心、好奇和参与感主动打开” | 写清主动行为的内在动机，这是产品长期价值的一部分。 |
| 一句话同时容纳动机、动作和结果 | 主动拆开“随手看看”与“产生话题、增加交流” | 关键因果可分句强调，但润色时补齐主语和连接关系。 |
| 同时比较米家与快手 | 只保留米家 | 优先使用最接近产品形态或战略问题的单一 benchmark，避免数字喧宾夺主。 |
| 使用“产品同时……” | 删除不必要的“同时” | 减少机械过渡词，能直接说就直接说。 |

## 第二轮：简历压缩与可面试性

| 原稿倾向 | 用户修改方向 | 可复用规则 |
|---|---|---|
| 为贴近 BRM，把具体生活语言改写成岗位框架词 | 保留“没听见还是出了危险”等人的原话 | 岗位匹配通过选择什么事实来写体现，不通过把原话翻译成抽象术语体现。 |
| 为压缩而删除市场判断 | 恢复目标人群、规模情景、相邻消费、benchmark 与 Agent 时代注意力判断 | 压缩优先删次要模块，不删本人最独特、最能展开的判断。 |
| 用 OEM/API 等实施路线补齐商业链条 | 删除本人不掌握、被追问时讲不透的实施内容 | 简历只放本人可以连续接受追问的内容；项目完整性不能替代候选人的真实 ownership。 |
| 默认三条 bullet 应接近等长 | 允许核心项目更长，其他经历更短 | 版面服从证据密度；只要长段仍是一条因果链，就不为形式等长牺牲关键判断。 |
| 罗列 AI 执行事项但不写最终交付 | 补出可交互原型、品牌片、商业方案和上线案例页 | 先分清本人判断与 AI 执行，再用可检查的交付物结束。 |

本轮进一步确认：简历不是项目目录，也不是完整商业计划书。它的作用是留下少数面试入口，使招聘者愿意追问，而用户能用真实事实继续讲透。

## 润色时怎样保留原意

用户的修改优先级高于原稿。只修复下面三类问题：

1. **残句**：例如“完全不知道……”可并入前句，用冒号或破折号承接。
2. **搭配不顺**：例如“是一种面对未知的恐惧感”可改为“更是面对未知时的恐惧”。
3. **因果连接不清**：例如“是主动的因为……”可改为“而是出于……主动……”。

不要借润色做下面这些事：

- 删除“恐惧、负担、幸福”等有立场的词；
- 把“主动打开”弱化成“提升使用频率”；
- 用“用户痛点、价值赋能、生态闭环”等泛化术语替换具体行为；
- 恢复用户已经删掉的比较、解释或防御性话语。

## 本轮推荐句式

这些句式展示语法修复方向，不要求机械复用：

- “子女面对的不只是一次联系失败，更是面对未知时的恐惧——完全不知道父母此刻在哪里、正在做什么：只是没有听见、没有带手机，还是确实遇到了危险？”
- “KIN 的使命不只是降低风险，更是通过技术增加家人之间的连接，从而直接创造幸福。”
- “KIN 希望用户打开产品，不是为了被动处理告警，而是出于关心、好奇和参与感，主动看看父母今天过得怎样。”
- “生活片段由此自然变成话题，增加子女与父母之间的交流。”

后续每完成一项经历的用户改稿，只追加能够改变未来写作决策的新偏好；不把一次性的词语选择累积成僵硬模板。
