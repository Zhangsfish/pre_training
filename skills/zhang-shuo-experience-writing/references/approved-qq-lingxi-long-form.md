### [QQ 灵犀｜AI Native 智能连接平台](https://zhang-shuo-portfolio.vercel.app/work/qq-lingxi/)

腾讯 PCG 校园 AI 产品创意大赛｜产品负责人｜2026.05（累计约10天）

- 发现 QQ 里并不缺联系人、群和内容，缺的是在理解“一个人长期是什么样”以及“他这次具体想要什么”之后，帮助他找到真正合适的连接。通过 QQ-MBTI 的定制追问和用户校准形成长期人格画像，再通过需求访谈形成当前需求画像；系统据此匹配内容、人和 QQ 群。匹配完成后，个人 Agent 与目标人物或群的 Agent 在正式连接前确认适配点、边界和沟通方式，再向用户给出推荐理由、风险提醒及私聊开场白或入群申请。
- 判断外部 AI 已经积累了对用户的长期理解，而 QQ 拥有真实关系、群与小共同体资产；因此以具备传播性的 QQ-MBTI 作为画像冷启动入口，把两类资产连接起来，使 QQ 有机会从聊天与群工具升级为 AI 时代的智能连接层。
- 负责问题定义、产品架构、Agent 角色与交互逻辑、迭代需求和验收，通过任务拆解、约束设定与反复验收，使用 ChatGPT 完成代码和工程实现；累计约10天交付覆盖人格画像、需求访谈、人、群与内容匹配及 Agent 协商的可交互原型和产品演示，进入腾讯 PCG 校园 AI 产品创意大赛复赛。

## 使用说明

- 这是项目描述与面试母稿，不是最终简历长度。三条依次承担产品机制、平台战略、ownership 与交付。
- “累计约10天”来自本人确认；工作分布在初赛和复赛准备期，不能把 Git 首尾日期写成连续三周开发。
- 对外统一写 ChatGPT，不再区分 ChatGPT 与 Codex；本人拥有问题、定义、架构、需求和验收，ChatGPT 承担代码与工程实现。
- 战略不是孤立愿景。必须从“用户难以找到合适连接”的具体问题，经两层画像和 Agent 协商机制，推到外部 AI 的用户理解与 QQ 的真实关系资产，最后才得到智能连接层的判断。
