# 个人主页更新材料模板

复制下面各栏填写即可；没有的信息写“未知”，无需编造。可以把填写稿发在对话里。**仓库是公开的**：未公开研究、保密原片、私人联系方式、账号凭证或未获许可的素材先不要提交 GitHub；由接手对话从安全材料中提炼获准公开的版本。

## A. 这次要改什么

- 类型：`已有项目更新 / 新增项目 / 仅更新 App 状态或媒体 / 首页或个人介绍 / 简历同步 / 修链接 / 其他`
- 项目名称、建议英文名、现有项目 ID（若有）：
- 想改的位置：`首页 App 区 / 主视觉作品 / 补充经历 / 某篇详情 / 简历 / 不确定`
- 你想让访客首先理解的一句话：
- 是否希望改变现有排序、版式或增加独立详情页？若没有，写“保持现有框架”：
- 这次是否要求发布到正式网站？`是 / 先做 PR 给我看 / 暂不确定`：

## B. 事实与边界（每个变化尽量附来源）

- 项目时间、你的身份与所处阶段（截至哪一天）：
- 要解决的真实问题或需求：
- 你亲自做了什么决定、设计、实验或实施：
- 同伴、导师、公司、AI 各做了什么；哪些不能算作你的独立成果：
- 已交付的东西与可核验结果（链接、文件、截图、测试、用户反馈等）：
- 数字的口径、样本、单位、日期与性质（实测 / 估算 / 方案假设）：
- 当前状态：已完成、测试中、投稿/审核中、已发布等；尚未完成的部分：
- 哪些信息不能公开，或公开范围待确认：
- 支撑上述信息的来源路径、公开 URL 或可供审阅的材料：

## C. 希望出现在页面上的内容

- 中文标题与首页一句话（可只给关键词，让接手对话起草）：
- 详情页最重要的 3–5 个点：
- 需要保留的原话；你不希望出现的误解或夸大：
- 英文已有官方名称/术语/现成文案（没有则由接手对话翻译并复核）：
- 如需同步简历，目标版本及希望突出的一条经历：

## D. 图片、视频与链接（没有可留空）

| 类型 | 文件/URL 或现有仓库位置 | 中文/英文版本 | 来源与公开许可 | 想展示的位置及说明 |
| --- | --- | --- | --- | --- |
| 图片 |  |  |  |  |
| 视频 |  |  |  |  |
| Demo / 仓库 / 商店 |  |  |  |  |

视频若有不同语言，请标明各版本；只有一种语言时明确写出来。上传素材不等于批准公开，接手对话会核查可见个人信息、实验细节、字幕及音轨。

## E. 验收时看什么

- 你最在意的事实、措辞或视觉效果：
- 中文与英文都需要检查的页面：
- 是否有截止日期或必须先处理的依赖：
- 仍需你决定的主观选择（如排序、公开范围、是否上线）：

提交后，接手对话应先对照仓库已有事实和页面，给出一份精简变更范围；只有缺失信息会影响真实性、公开许可或关键排序时才集中提问。完成后提供 PR、中文/英文页面预览、测试结果和本次发布状态。
