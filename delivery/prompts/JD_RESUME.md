# Maintenance task — 由一个真实JD生成定向简历

仅在用户提供/指定真实JD并要求适配时执行；不改变已完成网站。先读AGENTS、resume/ASSEMBLY、PRESETS、publication/claims、PROFILE和相关experience。不要从头问经历。

1. 读取JD真实内容，记录来源与日期；无内容/无法访问就准确说缺JD，不猜职位职责。
2. 列最多5项核心要求，匹配已有claim；有硬资格缺口直接说明，不靠关键词伪装。
3. 选择2–4段最相关经历，生成variant输入和短MATCH；本人/AI/团队贡献、数字与状态保持一致。默认排除词典、公众号、旁听清单。
4. 生成一页PDF与Markdown；运行resume:check、文本提取与逐页视觉检查。项目链接指向同一个站的稳定详情。
5. 具体投递分析与其他私人信息保留generated_private；公共仓库只提交被批准的脱敏选材/模板更新，实际PDF交给用户，未经要求不上传到网站、不发邮件/网申。
6. 提交审查材料，等待策划者接受；不可让实施者自签通过。报告附模板版本、source_snapshot、claim_ids、PDF hash、实际输出位置、发现的缺口。

这是维护任务，不解锁网站R06，也不重新排序主页。遇新事实先由策划者更新事实库再重生成受影响简历。
